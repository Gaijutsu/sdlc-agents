# Proposals

One file per pattern, in `open/` until decided, then moved to `accepted/` or `rejected/` with the decision filled in.
Template: `skills/sdlc-improve-process/references/proposal-template.md`.

- Anyone's improver adds evidence rows to an existing proposal when it sees the same pattern. Rows are append-only.
- A proposal is ready for a retro at three or more evidence rows from at least two runs.
- Rejected proposals keep their reasoning; it teaches the next retro what the team decided and why.

`metrics.md` collects one row per retro per teammate.
